# Mahindra BSVI Design System

- Platform: Android portrait
- Primary: #B71C1C
- Dark: #17202A
- Background: #F3F5F7
- Surface: #FFFFFF
- Radius: 14px cards, 11px inputs, 999px badges
- Minimum touch target: 56dp
- Primary typography: bold, high contrast
- Driver action cards: icon + title + one short subtitle
- Avoid dense menus and technical controls
- Driver/Mechanic actions are separate from Admin controls
- Never expose API URL, spreadsheet ID, session token, or backend settings in the UI
